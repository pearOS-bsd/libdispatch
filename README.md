# libdispatch

Grand Central Dispatch (queues, workqueues, sources) built for the pearOS system layer on top of the `darwinator` workqueue and kqueue emulation.

**Status: planned** — this repository is empty until the work starts.  It is one piece of a cache of our own for pearOS (see `docs/development/CACHE-LIBRARIES.md` in https://github.com/pearOS-bsd/docs).

Source: apple-oss-distributions/libdispatch (Apache 2.0).
